# 3联屏画面分割 · 信号方案说明（中日双语）

某项目「1 台 STB 输出画面三分割，由 3 块横向并排屏幕显示同一幅画面」的技术方案说明页面。

| 语言 | 路径 | 文件 |
| --- | --- | --- |
| 中文 | `/` | `index.html` |
| 日本語 | `/ja/` | `ja/index.html` |

两页右上角互有语言切换链接。

## 内容概要

- **方案一：2×2 矩阵**（推荐）— 标准 4K 信号，每块 1920×1080，无需定制固件
- **方案二：条形画面 3840×720** — 可直接使用条形素材，每块 1280×720，需定制固件
- 每个方案后带视频演示区（素材 → 分割后，点击同步播放；视频以 base64 内嵌于 HTML）
- 附「关于素材制作」章节：如何把三段 1920×1080 合成所需素材、常用工具

## 部署

Vercel 静态部署（无构建步骤）：仓库根目录即站点根目录。

- Framework Preset: **Other**
- Build Command / Output Directory: 留空（静态文件直接发布）

直接用浏览器打开 `index.html` 即可；日文版在 `ja/index.html`。
